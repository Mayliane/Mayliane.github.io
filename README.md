# Mayliane Lefebvre – Portfolio

Portfolio de projets de communication : identités visuelles, stratégies publicitaires, personas et événementiel.

🔗 **Site en ligne : https://mayliane.github.io/**

## Aperçu

Un portfolio interactif avec :
- un carrousel 3D de projets, avec écran d'intro animé
- une page dédiée par projet (`projet/<nom>.html`)
- un mode clair / sombre
- deux univers au choix : **May** et **UK70**
- des pages À propos et Contact

## Structure du dépôt

```
├── index.html            Page d'accueil (carrousel)
├── projet/               Une page HTML par projet
├── may.js                Univers « May »
├── london70.js           Univers « UK70 »
├── apropos.js            Page À propos
├── contact.js            Page Contact
├── mobile.js             Ajustements téléphone
├── extras.js             Compléments
├── transitions-index.js  Transitions entre pages
├── sound.js              Sons
├── 01.jpg … 15.jpg       Images de couverture
├── sitemap.xml           Plan du site pour Google
├── robots.txt            Consignes aux robots d'indexation
├── mentions-legales.html
└── cgu.html

## Hébergement

Le site est hébergé gratuitement avec **GitHub Pages**. Chaque modification poussée sur la branche principale est publiée en quelques minutes.

## Référencement

- Propriété validée dans Google Search Console (méthode balise HTML)
- `sitemap.xml` et `robots.txt` à la racine
